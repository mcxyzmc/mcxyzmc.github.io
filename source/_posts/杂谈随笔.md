今天在网上找网课资源时偶然间发现一篇很不错的在线知识库网页，感觉这种形式很适合用来做读书笔记、搭建个人知识库，于是顺藤摸瓜找到了[**语雀**]。仔细了解过后发现这个在线工具是真的很不错，只需要注册账号就能使用不需要繁琐的配置，工具非常完善了，网页渲染简约漂亮，最重要的是免费的就已经够用了，完美！！！好了，以下奉上语雀的介绍：
语雀是由蚂蚁集团（Ant Group）孵化的专业的云端知识库。与传统的在线文档不同，语雀的核心理念是**结构化知识管理**。它不以文件流的形式堆砌文档，而是采用**图书的目录结构**来组织内容，非常适合构建个人知识体系、编写技术文档、项目说明书或团队维基。
其核心功能亮点在于：

- 书卷式目录结构：提供类似书籍的左侧目录导航，支持多级层级，让碎片化的文档形成系统性的知识库。
- 强大的编辑器：采用块风格编辑器，支持 Markdown 快捷键，同时针对中文写作进行了深度优化。支持插入代码块（带高亮）、思维导图、流程图、LaTeX 公式、本地视频等多种富文本内容，真正做到“所见即所得”。
- 多端同步与导出：支持 Web、PC/Mac 客户端及移动端 App，数据实时同步。提供完善的数据导出功能，支持将单篇或整库导出为 PDF、Word、Markdown 或图片，数据迁移相对自由。
- 权限与协作：拥有细粒度的权限控制（私密、指定人可见、互联网公开），支持多人实时协同编辑、评论互动及历史版本回溯。

个人免费版权益：

- 容量限制：目前提供 10GB 的上传流量/总容量，单文件上传限制通常为 1GB，对于纯文本和图文笔记来说几乎是用不完的。
- 功能限制：个人用户可免费使用绝大部分核心编辑与整理功能，主要限制在于高级协作（如超过一定人数的团队协同）及知识库数量。
- 公开性限制：免费用户无法开启“互联网公开”功能，你的知识库只能你自己（或少数协作者）看，无法生成公开链接作为博客或教程网站分享给他人。

今天在写文章的时候发现部分公式 markdown 中能正常显示但是上传到网站却无法正常渲染的问题，据说是渲染引擎的问题：Hexo 默认使用的 Markdown 渲染引擎是 hexo-renderer-marked。这个引擎主要针对标准 Markdown，它会把 LaTeX 中的下划线 _ 误认为是 斜体（Italic） 的标记，把反斜杠 \ 误认为是转义字符。解决方法呢也很简单，直接执行以下更换渲染引擎为 kramed就行了（记得在本地网站目录下以管理员身份运行）：

```bash
npm uninstall hexo-renderer-marked
npm install hexo-renderer-kramed --save
hexo clean
hexo g
```
